# 🌿 우리가족챙기기 (Family Care)

우리 가족의 매일 아침 출근·등교부터 주말 외식·나들이, 긴급 야간/휴일 의료까지 한 번에 챙겨주는 **스마트 데일리 라이프 & 건강 비서 모바일 웹앱**입니다.

---

## 🌟 주요 핵심 기능 (6대 위젯)
1. **☀️ 오늘의 날씨 & 옷차림 / 우산 알림**: 기온·체감온도 분석을 통한 맞춤 옷차림 추천 및 강수확률 40% 이상 시 우산 알림
2. **🚌 나만의 실시간 교통 루트**: 집 앞 정류장(평내유진아파트 M2323, 165 등) 실시간 도착 잔여시간 카운트다운
3. **🏥 우리동네 병원 & 당번약국**: 휴일/주말 문 연 약국, 소아 야간 달빛어린이병원, 응급의료기관 원클릭 필터 및 바로 전화걸기
4. **🍽️ 우리 가족 단골 식당 & 주말 외식**: 단골 식당 영업시간, 주말 마감 시간, 휴무일 및 가족 메모 관리
5. **🩺 알레르기 & 감염병 예보**: 환절기 꽃가루 농도 위험도 및 감기/식중독 위험도 예보
6. **🎪 주말 나들이 & 축제 / 붐빔 신호등**: 인근 지역 축제 및 행사, 실시간 인구 혼잡도(신호등) 제공

---

## 🎨 UX/UI 디자인 컨셉
* **Fresh Pastel Neo-Glassmorphism**: 산뜻한 파스텔 메쉬 그라디언트 + 반투명 블러 카드
* **Context-Aware Layout**: 평일 아침엔 교통/우산 카드가 상단으로, 주말엔 병원/외식/나들이 카드가 자동으로 우선 배치
* **Mobile-First & BFCache**: 스마트폰 백그라운드 복귀 및 자정 롤오버 시 자동 데이터 갱신

---

## 🚀 빠른 시작 (Local Test)

```bash
# 가상환경 및 패키지 설치
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 서버 실행
python3 -m backend.main
```
브라우저에서 `http://localhost:8000` 접속

---

## 🐳 Docker & Synology Portainer 배포

```bash
# 도커 빌드 및 백그라운드 실행
docker compose up -d --build
```
* 서비스 포트: `3090` (외부 접속: `http://<NAS_IP>:3090`)
* 데이터 볼륨: `family_care_data` ➔ `/app/data` (SQLite 영구 보존)
