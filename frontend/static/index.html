📲 홈 화면에 정식 앱(PWA) 설치하기
✨ 1. 구글 크롬 (Chrome) - 가장 추천!
1. 상단 주소창 오른쪽의 [설치 📥] 아이콘 터치
또는 우측 상단 메뉴(⋮) ➔ [앱 설치] 선택 시 브라우저 주소창 없는 100% 독립 앱으로 설치됩니다.
🤖 2. 삼성인터넷 (갤럭시 브라우저)
1. 우측 하단 메뉴(≡) ➔ [현재 페이지 추가] 터치
2. 팝업에서 '홈 화면'이 아닌 👉 [앱 (App)]을 선택해야 브라우저 뱃지 없는 정식 독립 앱으로 설치됩니다!
(또는 주소창 오른쪽 다운로드 화살표 📥 터치)
⚠️ 3. 네이버 웨일 (Whale) 유의사항
네이버 웨일은 브라우저 자체 정책상 정식 앱(WebAPK) 설치 대신 웨일 북마크 바로가기 링크로 저장됩니다. 브라우저 껍데기 없는 독립 앱으로 설치하려면 크롬 또는 삼성인터넷을 사용하세요!
🍎 4. 아이폰 / 아이패드 (사파리 Safari)
하단 중앙의 공유 버튼 (⎋ 네모에 화살표) 터치 ➔ [홈 화면에 추가 ➕]를 선택하세요.
